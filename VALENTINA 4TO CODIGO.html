Sobre esta pagina

Esta pagina web fue creada como ejemplo educativo para practicar la estructura basica de HTML y el diseno visual utilizando CSS. El objetivo es aprender a organizar contenido, crear secciones, aplicar colores, usar tarjetas, tablas y formularios.

Todo el codigo se encuentra dentro de un solo documento, por lo que no es necesario crear archivos separados. Esto permite comprender mejor como se relaciona el contenido HTML con los estilos CSS.

Conocer mas

HTML

HTML sirve para crear la estructura de una pagina web. Permite agregar titulos, parrafos, enlaces, formularios, tablas e imagenes.

CSS

CSS se utiliza para dar estilo a la pagina. Con CSS se pueden cambiar colores, tamanos, margenes, bordes y la distribucion de los elementos.

Diseno Web

El diseno web combina estructura y estilo para crear paginas ordenadas, atractivas y faciles de usar para los visitantes.

Servicios de la pagina

  • Creacion de paginas web informativas.
  • Diseno de secciones con tarjetas.
  • Organizacion de contenido usando HTML.
  • Aplicacion de colores, bordes y sombras con CSS.
  • Creacion de formularios basicos de contacto.
  • Uso de tablas para mostrar informacion ordenada.
